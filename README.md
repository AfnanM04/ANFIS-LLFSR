# ANFIS-LLFSR
### Adaptive Neuro-Fuzzy Inference System for Low-Light Face Super-Resolution

ANFIS-LLFSR is a hybrid deep learning framework that combines Adaptive Neuro Fuzzy Inference Systems (ANFIS), Zero DCE, RRDB, SwinIR, and ArcFace guided identity preservation to reconstruct high quality facial images from low light, low resolution inputs.

## Overview

ANFIS-LLFSR is a hybrid deep learning framework designed to reconstruct high resolution facial images from severely degraded low light, low resolution inputs.

Unlike conventional super resolution methods that rely solely on convolutional neural networks or transformer architectures, ANFIS-LLFSR integrates the reasoning capability of an Adaptive Neuro-Fuzzy Inference System (ANFIS) with state-of-the-art image enhancement and super-resolution techniques.

The framework combines

- Zero-DCE for unsupervised low-light enhancement
- Adaptive Neuro-Fuzzy Inference System (ANFIS)
- RRDB (Residual-in-Residual Dense Blocks)
- Spatial Feature Transform (SFT)
- SwinIR Transformer
- Landmark Structure Consistency
- ArcFace Identity Preservation

to generate visually realistic and identity-preserving high-resolution face images.

---

# Motivation

Face recognition systems deployed in surveillance, security, and intelligent transportation often fail under challenging lighting conditions.

Low illumination introduces

- severe noise
- loss of facial texture
- reduced contrast
- missing identity information

Traditional super-resolution networks attempt to restore resolution but often ignore illumination characteristics, leading to blurred textures and identity distortion.

ANFIS-LLFSR addresses this limitation by allowing a neuro-fuzzy reasoning module to estimate illumination characteristics before the super-resolution process begins.

This enables the restoration network to adapt dynamically to different lighting conditions rather than treating every image identically.

# Pipeline

### Stage 1 — Image Enhancement

The degraded facial image first passes through Zero-DCE, where illumination is enhanced without requiring paired datasets.

Outputs:

- Improved brightness
- Better contrast
- Reduced illumination degradation

---

### Stage 2 — Neuro-Fuzzy Illumination Modeling

Instead of relying on fixed enhancement parameters, ANFIS estimates illumination conditions using fuzzy inference rules.

This module learns

- illumination intensity
- local brightness variations
- nonlinear lighting characteristics

and generates adaptive enhancement coefficients.

---

### Stage 3 — Feature Extraction

Deep features are extracted using Residual-in-Residual Dense Blocks (RRDB).

RRDB enables

- rich texture recovery
- stable gradient propagation
- improved detail reconstruction

---

### Stage 4 — Spatial Feature Transformation

The illumination information generated by ANFIS is injected into intermediate feature maps through Spatial Feature Transform (SFT).

This allows the network to adapt its feature representations according to estimated lighting conditions.

---

### Stage 5 — Transformer Refinement

SwinIR performs global attention over feature windows.

Advantages include

- long-range dependency modeling
- global texture consistency
- sharper reconstruction
- better facial details

---

### Stage 6 — Landmark Preservation

A facial landmark consistency loss ensures structural correctness of

- eyes
- nose
- mouth
- facial contours

thereby reducing geometric distortion.

---

### Stage 7 — Identity Preservation

ArcFace embedding loss forces reconstructed faces to remain close to their original identity representation.

This minimizes identity drift during reconstruction.

---

# Dataset

The framework is trained using the CelebA Dataset.

Synthetic degradation is applied to generate realistic low-light images.

The degradation pipeline includes

- Downsampling
- Gaussian Blur
- Motion Blur
- Poisson Noise
- Low Illumination
- JPEG Compression

# Loss Functions

The total loss combines multiple objectives.

### Pixel Loss

Maintains reconstruction accuracy.

### Perceptual Loss

Improves visual realism.

### GAN Loss

Produces sharper textures.

### ArcFace Identity Loss

Preserves facial identity.

### Landmark Consistency Loss

Maintains facial geometry.

Overall objective:

L = λ₁Lpixel + λ₂Lperceptual + λ₃LGAN + λ₄Lidentity + λ₅Llandmark
